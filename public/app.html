🔧 Maintenance Changes

Mileage column added. Invoice # column added. Driver column removed. All new entries are editable (✏ icon). Historical entries from REPAIR file are read-only base data.

🚚 Equipment Changes

Color-coded status badges: In Use (green), Returned (yellow), Sold (grey), Rental (teal). Plate expiry tracked separately from inspection expiry — both show 60/30/15 day alerts. Search/filter by unit, VIN, plate, type, status. All editable.

🏢 Broker Auto-Complete

All 100+ brokers from load history are auto-seeded. When entering a new load, type 3+ letters in the Customer/Broker field to see a dropdown. Click to auto-fill. Full broker profiles (MC#, credit, contact) in Brokers tab.
